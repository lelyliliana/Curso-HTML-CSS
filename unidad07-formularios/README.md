# Unidad 07 — Formularios

```html
<label for="correo">Correo</label>
<input id="correo" name="correo" type="email" required>
```

## label
Placeholder no sustituye label.

## Tipos
email, number, date, checkbox, radio, etc.

## Agrupación
fieldset/legend para grupos relacionados.

## Validación
HTML puede expresar restricciones básicas, pero el servidor debe validar nuevamente cuando exista backend.

## Reto
Crea formulario de registro accesible con mensajes/instrucciones comprensibles.
