# Unidad 01 — Documento HTML

```html
<!doctype html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi sitio</title>
</head>
<body>
  <h1>Hola</h1>
</body>
</html>
```

## Elementos
Etiqueta, atributo, contenido y anidación.

## lang
Ayuda a tecnologías de asistencia y procesamiento del contenido.

## viewport
Fundamental para comportamiento móvil.

## Reto
Construye un documento válido con título y estructura básica.
