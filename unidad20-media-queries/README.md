# Unidad 20 — Media queries

```css
@media (min-width: 48rem) {
  .layout { grid-template-columns: 2fr 1fr; }
}
```

## Breakpoints
Elige cuando el contenido necesita cambiar, no por modelos concretos de teléfono.

## Preferencias
```css
@media (prefers-reduced-motion: reduce) { ... }
```

## Reto
Define breakpoints justificándolos con el punto donde el layout deja de funcionar bien.
