# Unidad 13 — Color, fondos y bordes

## Color
Puede expresarse mediante hex, rgb/hsl y otras sintaxis modernas.

## Contraste
No uses color como único medio para comunicar estado.

## Variables
Aunque se profundizan después:
```css
:root { --surface: #fff; }
```

## Reto
Diseña estados normal/error/éxito donde además del color exista texto o iconografía comprensible.
