# Unidad 05 — HTML semántico

Elementos:
- header;
- nav;
- main;
- section;
- article;
- aside;
- footer.

## Regla
No elijas una etiqueta porque “se ve igual”. Elige por significado.

## section
Normalmente tiene un tema identificable, frecuentemente con encabezado.

## article
Contenido autocontenido/reutilizable.

## Reto
Reestructura una página llena de divs usando elementos semánticos donde corresponda.
