# Práctica del taller integrador

[Lección y enunciado](README.md) · [Índice](../README.md) · [Siguiente: proyecto final](../unidad32-proyecto-final/README.md)

Completa las cinco etapas del enunciado de biblioteca. Mantén una carpeta con tus archivos y un documento de decisiones. El resultado mínimo consta de Inicio, Talleres, Contacto y Resultado, una hoja CSS y todos los recursos locales.

## Registro de aceptación

| Tarea | Condición | Resultado esperado | Evidencia |
|---|---|---|---|
| Elegir Robótica desde Inicio | Mouse y teclado | Talleres con destino robotica | |
| Leer horario | Pantalla estrecha | Datos y encabezados disponibles | |
| Formulario vacío | Activar submit | Permanece en Contacto con validación | |
| Datos ficticios válidos | Completar campos | Resultado de demostración, sin envío real | |
| Abrir detalles | Tab y teclado | Respuesta visible y control operable | |
| Ampliar | 200% | Contenido y foco sin recortes | |
| Reducir movimiento | Preferencia reduce | Sin movimiento dependiente de transición | |
| Cargar bajo HTTP | Network | Recursos locales sin 404 | |

## Ampliación

Añade un taller de ciencia con horario y materiales propios. Debe aparecer en Inicio, Talleres y en las opciones del formulario. Revisa enlaces, encabezados y variantes: no basta con una tarjeta que no tenga destino.
