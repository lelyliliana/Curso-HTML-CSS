# Unidad 29 — SEO técnico básico y metadatos

## title
Único y descriptivo.

## meta description
Resume la página.

## headings
Jerarquía de contenido, no truco SEO.

## canonical
Útil en escenarios de contenido duplicado; no se añade sin entender la URL preferida.

## Open Graph
Mejora presentación al compartir.

## Reto
Crea head completo para una página real sin rellenar metadatos con palabras clave artificiales.
