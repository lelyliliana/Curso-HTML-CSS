**[Comenzar el curso: Unidad 00: Cómo funciona la Web y preparar el entorno](unidad00-web-entorno/README.md)**

Puedes leer las lecciones aquí sin conocer GitHub. Al terminar cada unidad, usa **Siguiente unidad** para avanzar; **Unidad anterior** y **Volver al índice** te permiten regresar.

[Ver el curso en Aprende con Leli](https://lelyliliana.github.io/aprende-con-leli/cursos/html-css/)

**Versión 1.1**

Curso abierto para aprender a construir **sitios web semánticos, accesibles, responsivos y mantenibles** con HTML y CSS.

No requiere experiencia previa en desarrollo web.

## Cómo practicar

1. [Prepara el entorno en Ubuntu, Windows o macOS](docs/ENTORNO.md).
2. Sigue las unidades en orden. Las unidades 00 a 30 incluyen una carpeta ejemplo con HTML y CSS completos.
3. En cada unidad realiza PRACTICA.md y compara después con SOLUCIONES.md. Ambas páginas tienen enlaces de regreso y avance.
4. Integra lo aprendido en el taller de biblioteca y el proyecto final. Consulta [el sitio completo de referencia](ejemplos/sitio-final/README.md).
5. Para publicar tu propia solución sigue [la guía de GitHub Pages](docs/PUBLICAR.md).

Los ejemplos se abren desde una copia descargada del repositorio. GitHub muestra código fuente, no ejecuta el HTML como página. Puedes leer sin conocer Git y descargar con Code > Download ZIP.

## Objetivo

Al finalizar podrás:

- comprender cómo se estructura un documento web;
- utilizar HTML semántico;
- organizar contenido con encabezados, listas, enlaces, imágenes y tablas;
- construir formularios accesibles;
- comprender el modelo de caja y la cascada;
- utilizar selectores, unidades, tipografía y color;
- diseñar layouts con Flexbox y Grid;
- crear interfaces responsivas;
- aplicar media queries;
- utilizar variables CSS;
- diseñar componentes reutilizables;
- mejorar accesibilidad y experiencia de usuario;
- organizar CSS mantenible;
- publicar un sitio estático;
- construir un proyecto final completo.

## Alcance

Este curso enseña HTML y CSS. La programación con JavaScript y el desarrollo con React se mantienen como cursos independientes.

## Principio

> HTML describe el contenido y su significado; CSS define su presentación. Una interfaz bonita que no es comprensible, accesible o adaptable sigue siendo una interfaz incompleta.
