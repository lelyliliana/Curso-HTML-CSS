# Curso de HTML y CSS desde cero

**Versión 1.0**

Curso abierto para aprender a construir **sitios web semánticos, accesibles, responsivos y mantenibles** con HTML y CSS.

No requiere experiencia previa en desarrollo web.

## Objetivo

Al finalizar podrás:

- comprender cómo se estructura un documento web;
- utilizar HTML semántico;
- organizar contenido con encabezados, listas, enlaces, imágenes y tablas;
- construir formularios accesibles;
- comprender el modelo de caja y la cascada;
- utilizar selectores, unidades, tipografía y color;
- diseñar layouts con Flexbox y Grid;
- crear interfaces responsivas;
- aplicar media queries;
- utilizar variables CSS;
- diseñar componentes reutilizables;
- mejorar accesibilidad y experiencia de usuario;
- organizar CSS mantenible;
- publicar un sitio estático;
- construir un proyecto final completo.

## Alcance

Este curso enseña HTML y CSS. La programación con JavaScript y el desarrollo con React se mantienen como cursos independientes.

## Principio

> HTML describe el contenido y su significado; CSS define su presentación. Una interfaz bonita que no es comprensible, accesible o adaptable sigue siendo una interfaz incompleta.
