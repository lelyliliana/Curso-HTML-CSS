# Unidad 32 — Proyecto final

Construye un sitio multipágina o landing completa.

## Requisitos
- HTML semántico;
- navegación;
- imágenes accesibles;
- formulario cuando aplique;
- CSS externo;
- Flexbox/Grid;
- responsive;
- foco visible;
- contraste;
- estados;
- metadatos;
- optimización básica;
- publicación;
- README reproducible.

## Regla
No se evalúa solo apariencia. Se evalúan estructura, adaptación, accesibilidad y mantenibilidad.
