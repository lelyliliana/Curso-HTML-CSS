# Unidad 08 — Accesibilidad HTML

## Principios prácticos
- estructura semántica;
- teclado;
- texto alternativo;
- labels;
- títulos claros;
- idioma;
- enlaces descriptivos.

## ARIA
HTML nativo primero. No agregues ARIA cuando un elemento nativo ya expresa la semántica.

## Teclado
Prueba Tab, Shift+Tab, Enter y controles.

## Reto
Audita una página solo con teclado y documenta barreras encontradas.
