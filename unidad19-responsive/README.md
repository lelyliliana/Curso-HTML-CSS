# Unidad 19 — Diseño responsive

Responsive no significa crear una versión móvil y otra escritorio.

## Principios
- contenido flexible;
- layouts adaptables;
- imágenes fluidas;
- breakpoints por contenido.

## Mobile-first
Puede simplificar progresión:
base → ampliar cuando hay espacio.

## Reto
Diseña una página que funcione desde 320 px hasta escritorio sin scroll horizontal.
