# Unidad 02 — Texto, jerarquía y contenido

## Encabezados
h1–h6 expresan jerarquía, no tamaño visual.

## Contenido
p, strong, em, blockquote, ul, ol, li.

## Semántica
Usa strong/em por significado, no solamente por apariencia.

## Reto
Convierte un texto plano en una página con jerarquía lógica y listas.
