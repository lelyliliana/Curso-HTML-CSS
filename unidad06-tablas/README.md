# Unidad 06 — Tablas

Las tablas representan **datos tabulares**, no layout.

```html
<table>
 <caption>Ventas mensuales</caption>
 <thead><tr><th scope="col">Mes</th><th scope="col">Ventas</th></tr></thead>
 <tbody><tr><th scope="row">Enero</th><td>120</td></tr></tbody>
</table>
```

## Accesibilidad
caption y encabezados ayudan a comprender relaciones.

## Reto
Representa datos reales con encabezados de fila/columna adecuados.
