# Unidad 15 — Flujo normal y display

Antes de Flex/Grid comprende el flujo normal.

## block / inline / inline-block
Cada modo participa distinto en layout.

## display:none
Retira el elemento del layout y del árbol de accesibilidad visual/interactivo en la práctica habitual; no lo uses para contenido que deba seguir disponible.

## Reto
Construye layout simple primero sin Flex/Grid y observa el flujo.
