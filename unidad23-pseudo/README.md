# Unidad 23 — Pseudoclases y pseudoelementos

Pseudoclases:
:hover, :focus-visible, :checked, :disabled, :nth-child(), :has() según soporte requerido.

Pseudoelementos:
::before, ::after, ::selection.

## Interacción
No diseñes estados solo para hover: teclado/touch también existen.

## Reto
Crea componente con hover, focus-visible, disabled y estado seleccionado.
