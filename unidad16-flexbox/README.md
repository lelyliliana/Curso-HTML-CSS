# Unidad 16 — Flexbox

Ideal para distribución principalmente en **una dimensión**.

```css
.toolbar {
 display:flex;
 gap:1rem;
 align-items:center;
 justify-content:space-between;
}
```

## Ejes
main axis y cross axis.

## flex
grow, shrink, basis.

## Reto
Construye navegación, grupo de botones y tarjetas con alturas variables.
