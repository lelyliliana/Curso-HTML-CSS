# Unidad 24 — Transiciones y animaciones

```css
.button { transition: transform .2s ease; }
.button:hover { transform: translateY(-2px); }
```

## Movimiento
Debe aportar feedback/comprensión, no distraer.

## Reduced motion
Respeta preferencias cuando el movimiento sea significativo.

## Rendimiento
Transform/opacity suelen ser opciones eficientes para animaciones simples.

## Reto
Diseña feedback sutil y versión reducida.
