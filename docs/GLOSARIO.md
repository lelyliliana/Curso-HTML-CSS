# Glosario

[Índice](../README.md) · [Primera unidad](../unidad00-web-entorno/README.md)

| Término | Significado en el curso |
|---|---|
| HTML | Lenguaje que describe contenido y relaciones mediante elementos y atributos. |
| CSS | Lenguaje que define presentación; sus declaraciones compiten mediante la cascada. |
| Elemento | Unidad de estructura representada por una etiqueta y, cuando corresponde, contenido y cierre. |
| Atributo | Información adicional de un elemento, como lang, href, id o name. |
| DOM | Representación del documento que construye el navegador; puede diferir del texto fuente. |
| Ruta relativa | Destino resuelto respecto de la URL del recurso que la utiliza. |
| Fragmento | Parte de una URL después de #, utilizada aquí para localizar un id. |
| Semántica | Significado y relaciones del contenido, independientes de su apariencia. |
| Nombre accesible | Nombre que una herramienta puede asociar con un control u objeto; debe ser útil y coherente. |
| Foco | Elemento al que se dirigen acciones de teclado; necesita una señal visible. |
| Cascada | Proceso de selección de declaraciones por origen, importancia, capas y otros criterios. |
| Especificidad | Peso de un selector comparado en el contexto correspondiente de la cascada. |
| Herencia | Recepción de determinados valores desde un ancestro; no todas las propiedades se heredan. |
| Box model | Capas de contenido, padding, borde y margen de una caja. |
| Flujo normal | Distribución básica del documento antes de técnicas que alteran su colocación. |
| Flexbox | Distribución centrada en un eje principal y uno transversal. |
| Grid | Distribución con coordinación de pistas en filas y columnas. |
| Viewport | Área de referencia de visualización, medida en píxeles CSS para las consultas utilizadas. |
| Reflujo | Reacomodo del contenido al cambiar espacio o ampliación sin perder información o acciones. |
| Breakpoint | Condición en la que el diseño cambia para responder a necesidades del contenido. |
| Token | Valor con nombre que expresa una decisión común del sistema visual. |
| Media query | Condición para aplicar reglas según espacio o preferencias. |
| Contraste | Relación entre luminancias de los colores efectivos, evaluada según el tipo de contenido. |
| GET | Método HTTP usado en las demos para expresar datos en la URL; no es apropiado para datos sensibles. |
| Validación nativa | Comprobación que realiza el navegador según atributos; no sustituye validación de servidor. |
| Sitio estático | Sitio servido como archivos; no añade procesamiento de formularios por sí solo. |
| LCP | Métrica de presentación de contenido principal visible; requiere medición en contexto. |
| Caché | Reutilización de recursos almacenados que puede alterar una comparación de cargas. |
