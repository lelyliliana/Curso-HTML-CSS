# Diagnóstico HTML/CSS

## HTML
¿El elemento existe y está bien anidado?

## Ruta
¿El recurso devuelve 200 o 404?

## Selector
¿La regla selecciona el elemento?

## Cascada
¿Otra regla gana? Mira Styles/Computed.

## Caja
¿El problema es width, padding, margin u overflow?

## Layout
¿Flex/Grid está en el contenedor correcto?

## Responsive
¿El contenido necesita un breakpoint o puede ser fluido?

## Accesibilidad
¿teclado, foco, zoom y contraste funcionan?

## Regla
No agregues !important hasta “hacerlo funcionar”. Identifica por qué la regla no se aplica.
