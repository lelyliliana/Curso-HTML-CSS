# Referencias de consulta

[Índice](../README.md) · [Entorno](ENTORNO.md) · [Continuar: primera unidad](../unidad00-web-entorno/README.md)

Los ejemplos y explicaciones del curso son material educativo propio. Estas fuentes permiten comprobar semántica, comportamiento y opciones de las herramientas.

- [HTML Living Standard (WHATWG)](https://html.spec.whatwg.org/multipage/): elementos, atributos, formularios y comportamiento normativo.
- [MDN: HTML](https://developer.mozilla.org/es/docs/Web/HTML): consulta de elementos y ejemplos.
- [MDN: CSS](https://developer.mozilla.org/es/docs/Web/CSS): propiedades, selectores y valores.
- [MDN: Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout/Basic_concepts): pistas y distribución.
- [MDN: imágenes responsivas](https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Responsive_images): picture, srcset y sizes.
- [MDN: movimiento reducido](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion): preferencias de movimiento.
- [W3C WAI: formularios](https://www.w3.org/WAI/tutorials/forms/): etiquetas, instrucciones y agrupación.
- [W3C: contraste mínimo](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): criterio y excepciones.
- [W3C: reflujo](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): adaptación y casos bidimensionales.
- [W3C: tamaño de objetivo mínimo](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html): tamaño, separación y excepciones.
- [Nu HTML Checker](https://validator.w3.org/nu/): validación de documentos.
- [W3C CSS Validator](https://jigsaw.w3.org/css-validator/): validación CSS (su soporte de sintaxis moderna puede diferir del navegador).
- [VS Code: primeros pasos](https://code.visualstudio.com/docs/getstarted/overview) y [Live Preview de Microsoft](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server).
- [GitHub Pages: fuente de publicación](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Si una interfaz de herramienta cambia, consulta la documentación oficial y conserva el objetivo del procedimiento. No copies configuraciones de otra versión sin comprobar su contrato.
