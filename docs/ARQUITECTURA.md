# Arquitectura pedagógica

## Dependencias
Ninguna.

## Continuidad
HTML/CSS sirve como base para JavaScript y React.

## Reglas
- HTML semántico antes que divs genéricos.
- Accesibilidad desde el inicio, no como parche final.
- Mobile-first cuando aporte claridad.
- No fijar tamaños que rompan zoom o contenido.
- Flexbox y Grid según problema.
- Evitar !important como solución habitual.
- No depender de frameworks CSS para enseñar CSS.
- Respetar prefers-reduced-motion en animaciones relevantes.
- Formularios con label y estados comprensibles.
- Contraste y foco visibles.
- No prometer contenido futuro.
