# Unidad 30 — Publicación de un sitio estático

Un sitio HTML/CSS puede publicarse en servicios de hosting estático.

## Antes
- rutas relativas correctas;
- index.html;
- nombres de archivo consistentes;
- sin rutas locales;
- enlaces probados;
- 404/recursos verificados.

## GitHub Pages
Puede servir contenido estático desde un repositorio/configuración compatible.

## Reto
Publica un sitio y pruébalo desde otro dispositivo.
