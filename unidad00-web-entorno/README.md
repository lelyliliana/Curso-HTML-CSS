# Unidad 00 — Cómo funciona la Web y preparar el entorno

## Objetivo
Comprender navegador, servidor, URL, HTTP y archivos antes de crear una página.

```text
navegador → solicitud HTTP → servidor
navegador ← HTML/CSS/recursos ← servidor
```

## Entorno
Necesitas editor, navegador y una carpeta de proyecto.

```text
mi-sitio/
├── index.html
├── css/
└── img/
```

## DevTools
Aprende desde el inicio a inspeccionar elementos, estilos, red y consola.

## Reto
Crea una carpeta web mínima, abre index.html y localiza el documento en DevTools.
