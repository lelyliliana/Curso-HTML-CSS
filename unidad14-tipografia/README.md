# Unidad 14 — Tipografía

## Propiedades
font-family, size, weight, line-height, letter-spacing.

## Legibilidad
Ancho de línea, tamaño y espaciado influyen en lectura.

## Fuentes
Incluye fallbacks y considera costo de fuentes web.

```css
body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
}
```

## Reto
Diseña escala tipográfica coherente para título, subtítulo, cuerpo y texto auxiliar.
