# Unidad 25 — Componentes y arquitectura CSS

## Componente
HTML + clases + estados con responsabilidad visual clara.

Ejemplo:
```text
.card
.card__title
.card__body
.card--featured
```

No es obligatorio seguir BEM literalmente; importa consistencia y bajo acoplamiento.

## Capas
Organiza base, layout, componentes y utilidades según escala.

## Reto
Construye biblioteca mínima de botón, tarjeta, alerta y formulario.
