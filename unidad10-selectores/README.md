# Unidad 10 — Selectores y especificidad

```css
.card {}
.card__title {}
nav a {}
[data-state="active"] {}
```

## Evita
Selectores excesivamente profundos que acoplan CSS al árbol HTML.

## Especificidad
No “ganes guerras” añadiendo IDs o !important. Diseña reglas previsibles.

## Reto
Refactoriza CSS con alta especificidad hacia clases reutilizables.
